脑卒中后康复与家庭照护指南

脑卒中（俗称中风）包括脑梗死与脑出血，存活者常遗留偏瘫、言语不清、吞咽困难等问题。康复的目标是尽可能恢复生活自理能力、预防再次卒中与并发症。康复越早开始越好，但须在医生评估病情稳定后进行。

一、康复的基本原则

1. 早期介入：病情稳定后即可在床上进行被动与主动活动，避免长期卧床。
2. 循序渐进：训练量由小到大，以不引起明显疲劳与不适为度。
3. 持之以恒：康复以月为单位计算，家属的耐心陪伴比短期高强度训练更重要。
4. 专业指导：建议在康复科或社区康复机构指导下制定训练计划。

二、肢体功能训练

1. 良肢位摆放：偏瘫侧肢体用软枕支撑，防止关节变形与肩关节半脱位。
2. 被动活动：家属帮助活动肩、肘、腕、髋、膝、踝关节，动作轻柔缓慢。
3. 坐位与站立训练：从床上坐起、床边坐稳，再逐步过渡到扶站、扶走。
4. 步行训练：使用助行器或拐杖，地面保持干燥防滑，家属在患侧旁保护。
5. 手功能训练：抓握毛巾、拧瓶盖、拣豆子等日常小游戏有助于精细动作恢复。

三、言语与吞咽照护

1. 言语训练：从单词、短句开始，多鼓励、不催促，避免当众纠正造成挫败感。
2. 吞咽障碍：进食时坐直、低头吞咽，小口慢咽，不说话、不看电视。
3. 食物选择：从糊状、半流质逐步过渡，避免干硬、黏性大、易散落的食物。
4. 出现频繁呛咳、进食后声音变哑、发热，应警惕误吸性肺炎，及时就医。

四、并发症预防

1. 压疮：每2小时翻身一次，保持皮肤清洁干燥，检查骶尾、足跟等受压部位。
2. 关节挛缩：坚持每日关节活动度训练，避免患侧长期下垂。
3. 深静脉血栓：在医生允许下活动下肢，观察单侧腿肿、疼痛并及时就诊。
4. 便秘与尿路感染：保证饮水与膳食纤维，留置导尿管者按医嘱护理。

五、情绪与心理支持

卒中后抑郁较为常见，表现为情绪低落、不愿配合训练、失眠。家属应多倾听、多肯定，必要时陪同就诊心理科或拨打心理援助热线。

六、复诊与危险信号

突发口角歪斜、单侧肢体无力、言语含糊、剧烈头痛，应立即拨打120，尽量记录发作时间。日常需按医嘱服药，控制血压、血糖、血脂，定期复诊。
