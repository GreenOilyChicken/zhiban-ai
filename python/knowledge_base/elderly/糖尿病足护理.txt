老年糖尿病足预防与护理指南

糖尿病足是糖尿病常见的严重并发症，由下肢神经病变与血管病变共同引起，表现为足部麻木、感觉减退、皮肤干燥、伤口难以愈合，严重时可导致溃疡甚至截肢。老年糖尿病患者病程长、视力与灵活性下降，是糖尿病足的高危人群，预防远比治疗更重要。

一、为什么老年人更需重视

1. 神经感觉减退：脚被磨破、烫伤却感觉不到疼痛，容易延误发现。
2. 血液循环差：伤口供血不足，愈合缓慢，感染容易扩散。
3. 视力下降、弯腰困难：难以自行检查足底与趾缝。
4. 常合并高血压、血脂异常，进一步加重血管病变。

二、每日足部检查

1. 每天在光线充足处检查双足，包括足底、足跟、趾缝。
2. 视力不佳者可用镜子照足底，或请家属协助检查。
3. 重点观察：水泡、裂口、鸡眼、胼胝、颜色发黑或发紫、趾甲嵌甲。
4. 发现任何破溃都不要自行处理，应尽快到内分泌科或糖尿病足专科就诊。

三、洗脚与皮肤护理

1. 水温控制在37摄氏度左右，先用手肘或温度计试温，切勿用热水泡脚。
2. 不使用电热毯、热水袋、暖宝宝直接接触足部，谨防低温烫伤。
3. 洗后用柔软毛巾轻轻吸干，尤其擦干趾缝，避免用力揉搓。
4. 皮肤干燥者可涂抹润肤霜，但趾缝之间不要涂抹，防止潮湿滋生真菌。
5. 不使用刺激性强的药水、鸡眼膏自行处理。

四、鞋袜选择

1. 选择鞋头宽大、鞋底厚软、透气合脚的鞋子，避免尖头鞋、硬底鞋。
2. 新鞋先短时间试穿，逐步增加穿着时间，防止磨脚。
3. 穿鞋前用手检查鞋内有无异物、褶皱、线头。
4. 选择浅色、无紧口罗纹的棉袜，便于及时发现渗液或出血，袜口不可勒住脚踝。
5. 居家也不要赤脚行走，避免踩到尖锐物或烫伤。

五、趾甲修剪与日常禁忌

1. 趾甲应平剪，不要剪得过短或剪伤甲沟，视力不佳者建议由家属或专业人员处理。
2. 严禁自行使用刀片、剪刀挖除鸡眼、胼胝。
3. 戒烟，吸烟会明显加重下肢血管狭窄。
4. 在医生指导下控制血糖、血压、血脂，并定期做下肢血管与神经评估。

六、需要立即就医的信号

足部出现新发溃疡、伤口流脓、局部红肿发热、皮肤发黑、足部突然剧痛或完全失去感觉，都应尽快就医；伴高热、寒战等全身症状时应立即拨打120。
