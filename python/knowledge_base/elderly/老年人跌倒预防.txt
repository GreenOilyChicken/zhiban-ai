老年人跌倒预防与应急处理指南

跌倒是老年人最常见的意外伤害原因，也是导致骨折、颅脑损伤、卧床失能的重要诱因。多数跌倒并非"不小心"，而是环境风险、肌力下降、视力减退、用药影响等多种因素叠加的结果，因此大多数跌倒是可以预防的。

一、跌倒的常见原因

1. 身体因素：下肢肌力下降、平衡能力减退、骨质疏松、视力与听力下降。
2. 疾病因素：帕金森病、卒中后遗症、眩晕、心律失常、低血糖。
3. 药物因素：部分降压药、镇静催眠药、降糖药可能引起头晕或体位性低血压。
4. 环境因素：地面湿滑、光线不足、门槛台阶、杂物绊脚、鞋不合脚。
5. 行为因素：起立过猛、登高取物、夜间独自如厕、雨雪天外出。

二、居家环境改造要点

1. 卫生间与浴室铺设防滑垫，加装扶手，使用加高坐便器与洗澡椅。
2. 卧室到卫生间沿途安装夜灯，开关位置便于躺卧时触及。
3. 清除走道杂物，电线沿墙固定，地毯边缘用胶带固定或移除。
4. 常用物品放在腰部至肩部高度，避免使用凳子登高取物。
5. 门槛处做缓坡处理，楼梯两侧安装稳固扶手。

三、衣着与辅助器具

1. 选择合脚、防滑、鞋底有纹路的鞋，不穿拖鞋、不穿裤腿过长的裤子。
2. 视力不佳者应佩戴合适眼镜，并定期验光；听力下降会影响平衡，必要时佩戴助听器。
3. 平衡能力差者应使用手杖或助行器，长度以站立时手柄位于腕横纹处为宜。
4. 手杖底部防滑垫磨损后及时更换。

四、运动与日常习惯

1. 坚持平衡与肌力训练，如太极拳、单腿站立（扶稳桌椅）、坐立起身练习。
2. 起身遵循"三步法"：平躺30秒、坐起30秒、站稳30秒后再走。
3. 洗澡水温不宜过高，时间不宜过长，浴室门不要反锁。
4. 雨雪、大风天气尽量减少外出，外出避开湿滑路面与人流高峰。
5. 定期检查视力，并在医生指导下评估正在服用的药物是否增加跌倒风险，不可自行停药。

五、跌倒后如何处理

1. 不要急于起身，先原地感受有无剧痛、肢体变形、头晕。
2. 怀疑骨折或髋部疼痛时保持原位不动，呼叫他人帮助并拨打120。
3. 头部着地、服用抗凝药物者，即使当时无明显不适也建议就医排查。
4. 独居老人可佩戴紧急呼叫设备，或与家属约定每日联络时间。

六、长期管理提示

跌倒过一次的老人再次跌倒风险明显升高，建议到老年科或康复科做一次综合评估，包括肌力、平衡、视力、用药与居家环境。
