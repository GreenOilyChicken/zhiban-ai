杭州西湖适老化游览导览

西湖位于杭州市主城区西部，三面环山、一面临城，2011年以文化景观列入世界文化遗产名录。湖区大部分区域免费开放，步道平坦、休息点密集，是国内少有的适合老年游客慢节奏游览的大型景区。

一、交通与到达

1. 地铁1号线"龙翔桥"站、7号线"吴山广场"站等均可步行到达湖滨区域。
2. 公交多条线路沿湖设站，老年游客可凭当地老年卡或身份证享受相应优待。
3. 自驾建议停在湖滨、涌金门等正规停车场，节假日车位紧张，尽量错峰出行。

二、适老推荐路线（半日休闲版）

1. 湖滨公园集合 → 沿湖滨步道缓行至断桥残雪。
2. 白堤（平路，长约1公里）→ 平湖秋月 → 孤山 → 西泠印社。
3. 全程约3公里，步行1.5-2小时，沿途长椅与树荫充足。
4. 体力有限者可在湖滨码头乘游船直达三潭印月，减少步行距离。

三、景点与门票参考

1. 湖滨、白堤、苏堤、花港观鱼等区域免费开放。
2. 雷峰塔、三潭印月（含船票）等为收费景点，价格以景区最新公告为准。
3. 多数收费景点对60周岁以上游客有半价、70周岁以上免票等优待，需出示身份证。
4. 建议游览时间为春秋两季的上午，避开正午与节假日高峰。

四、无障碍与防滑提示

1. 湖滨与白堤、苏堤主步道平坦，可通行轮椅与助行器。
2. 断桥、孤山部分路段有缓坡，雨后石板路湿滑，务必穿防滑鞋。
3. 游船上下船有台阶，行动不便者建议由家属搀扶，并向工作人员申请协助。
4. 景区公厕分布较密，可提前在游客中心领取导览图。

五、休息与补给

1. 沿湖设有大量长椅、凉亭，建议每步行20-30分钟休息一次。
2. 湖滨商圈餐饮、便利店密集，可就近用餐、补充热水。
3. 夏季注意防晒防暑，随身携带水杯与常用药物。

六、老年游客特别提醒

1. 行程安排不宜过满，一天一个片区即可，避免连续多日高强度游览。
2. 结伴出行，随身携带写有家属联系方式的卡片。
3. 节假日人流密集，注意防止走散，约定集合点。
4. 遇雷雨、大风、高温预警天气，建议改为室内博物馆行程。
