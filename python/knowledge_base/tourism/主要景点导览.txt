文旅导览知识库

一、北京故宫博物院

故宫，又称紫禁城，位于北京中轴线的中心。始建于明永乐四年（1406年），历时14年建成，是明清两朝24位皇帝的皇宫。

开放信息：
- 开放时间：4月1日-10月31日 8:30-17:00（16:00停止入场）；11月1日-3月31日 8:30-16:30（15:30停止入场）
- 门票价格：旺季60元，淡季40元（65岁以上老人半价，70岁以上免票）
- 每周一闭馆（法定节假日除外）
- 建议游览时间：3-4小时

无障碍信息：
- 设有轮椅租借服务（免费，押金500元）
- 主要宫殿设有无障碍坡道
- 太和门至太和殿广场可轮椅通行

推荐路线（老年友好版）：
- 午门入 → 太和门 → 太和殿 → 中和殿 → 保和殿 → 乾清宫 → 御花园 → 神武门出
- 全程约2小时，可在沿途座椅休息

二、万里长城（八达岭）

八达岭长城是明长城中保存最好、最具代表性的一段。位于北京延庆区，距市区约70公里。

开放信息：
- 开放时间：旺季 6:30-19:00；淡季 7:30-18:00
- 门票价格：旺季40元，淡季35元（60岁以上半价，65岁以上免票）
- 缆车：单程100元，往返140元

无障碍信息：
- 设有轮椅坡道至南四楼
- 残疾人免费乘坐缆车

老年游客建议：
- 乘缆车上下，避免攀爬陡峭路段
- 南线较平缓，推荐游览南一至南四楼
- 携带饮用水和防晒用品

三、杭州西湖

西湖位于杭州主城区西部，三面环山。2011年被列入世界文化遗产。

开放信息：
- 全天免费开放（湖滨区域无需门票）
- 部分景点需单独购票：雷峰塔40元、三潭印月55元（含船票）
- 60岁以上半价，70岁以上免票

推荐路线（老年休闲版）：
- 湖滨公园 → 断桥残雪 → 白堤 → 平湖秋月 → 孤山 → 西泠印社
- 可乘坐游船：手划船150元/小时（可坐6人），电动船55元/人

四、西安秦始皇兵马俑博物馆

兵马俑位于西安市临潼区，距市区约40公里。1974年被发现，被誉为"世界第八大奇迹"。

开放信息：
- 开放时间：3月-11月 8:30-18:00；12月-2月 8:30-17:30
- 门票价格：120元（3月-11月），60元（12月-2月）
- 65岁以上免票

推荐游览：
- 一号坑（最大、最壮观）→ 三号坑（指挥部）→ 二号坑 → 铜车马展厅
- 建议聘请讲解员或租借语音导览

五、九寨沟

九寨沟位于四川省阿坝藏族羌族自治州，以翠海、叠瀑、彩林、雪峰、藏情"五绝"著称。

开放信息：
- 开放时间：7:00-17:00
- 门票：旺季169元+观光车90元；淡季80元+观光车80元
- 65岁以上免门票，观光车无优惠

游览提示：
- 景区内有观光车接驳，适合老年人游览
- 海拔较高（2000-3100米），注意高原反应
- 建议携带保暖衣物

六、泰山

泰山位于山东省泰安市，海拔1545米，被尊为"五岳之首"。

开放信息：
- 开放时间：全天
- 门票：115元（60岁以上半价，70岁以上免票）
- 索道：中天门-南天门100元/单程

老年游客建议：
- 推荐从天外村乘景区车至中天门（30元），再乘索道至南天门
- 避免徒步登十八盘（陡峭、费体力）
