千岛湖休闲度假适老导览

千岛湖位于浙江省杭州市淳安县，是上世纪五十年代建设新安江水电站形成的大型人工湖，湖中岛屿众多、水质优良、森林覆盖率高，空气清新，适合老年游客开展慢节奏的休闲度假式旅行。

一、交通与到达

1. 高铁至千岛湖站，转乘公交或出租车前往中心湖区码头。
2. 从杭州自驾约2小时，沿途为山区高速，注意行车安全。
3. 建议安排2-3天，以"住下来、慢下来"为主，避免一日往返。

二、主要游览方式

1. 中心湖区游船：经典线路，登梅峰岛、渔乐岛等，游船为主要代步工具，步行强度低。
2. 东南湖区游船：游客相对较少，环境更清静。
3. 环湖绿道：适合骑行与散步，可选择平坦路段短距离慢行。
4. 湖畔公园与观景平台：适合清晨、傍晚散步观景，无需门票。

三、适老推荐行程（两日版）

1. 第一天：抵达后入住湖边酒店，下午在湖滨公园散步，傍晚观日落。
2. 第二天：上午乘中心湖区游船（约4-5小时，含登岛），下午回酒店休息。
3. 第三天：上午环湖绿道短程漫步或参观本地村落，午后返程。
4. 每日户外活动控制在半天以内，留足午休时间。

四、门票与优惠参考

1. 千岛湖景区实行大门票加游船票的模式，具体价格与淡旺季政策以景区官方最新公告为准。
2. 景区通常对老年人、儿童等有优待，需凭身份证等有效证件，标准请提前在官方渠道确认。
3. 建议提前在线预订船票，避免旺季现场排队。

五、无障碍与安全提示

1. 游船上下船有台阶与跳板，行动不便者须由家属搀扶，并向工作人员申请协助。
2. 登岛步道多为缓坡与台阶，部分路段较陡，建议使用手杖，穿防滑运动鞋。
3. 乘船全程穿好救生衣，不要在船舷边站立或探身拍照。
4. 湖区天气多变，夏季防晒防暑，冬季注意保暖，雨天路滑减少登岛。

六、饮食与住宿

1. 千岛湖有机鱼头为当地特色，建议选择清淡做法，注意少油少盐。
2. 老年游客吃鱼时注意鱼刺，可请店家代为处理。
3. 选择湖景酒店时优先考虑有电梯、离码头近、医疗配套便利的位置。
4. 山区夜间温差大，注意保暖，避免受凉。

七、老年游客特别提醒

1. 湖区部分路段海拔与坡度变化明显，有心脑血管疾病者应量力而行，随身携带常用药物。
2. 乘船时间较长，出发前不要过饱或空腹，晕船者可提前咨询医生。
3. 随身携带身份证、常用药物与家属联系方式卡片，尽量结伴出行。
4. 旺季游客较多，注意防走失，约定集合地点。
