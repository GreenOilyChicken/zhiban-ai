## 1. 系统简介

「知伴AI」是一套**双端智能体平台**，面向**政务、银发经济与文旅**三大方向，
提供政策咨询、康养指导与文旅导览服务。

### 1.1 系统组成

| 端 | 技术 | 使用者 | 说明 |
|---|---|---|---|
| **用户端 Web** | Vue 3 + Element Plus | 普通用户 | 浏览文章、查政策、政策问答、帮助中心 |
| **管理端 Web** | Vue 3 + Element Plus | 管理员 | 文章管理、政策管理、配额管理、知识库上传 |
| **微信小程序** | 原生小程序 | 普通用户（移动端） | 三大智能体对话、语音、用药指导、政策查询、文旅导览、个人中心 |
| **Java 后端** | Spring Boot 3.2.5 | — | 业务接口、JWT 认证、配额、WebSocket |
| **Python AI 服务** | FastAPI + LangChain + ChromaDB | — | 智能体对话、向量检索、知识库构建 |

> **重要**：用户端 Web 与小程序是**两个独立入口**。
> 用户端 Web **没有**智能体对话页面；对话能力在**微信小程序**中提供。

### 1.2 三大方向

| 方向 | 智能体标识 | 智能体名称 | 能力 |
|---|---|---|---|
| 银发经济 | `elderly` | 银发康养助手 | 用药指导、护理建议、康复计划、长护险申请 |
| 政务服务 | `govpolicy` | 政务政策助手 | 政策检索、政策解读、培训台账生成 |
| 文旅项目 | `tourism` | 文旅导览助手 | 景点导览、路线规划、文化故事 |

## 2. 访问入口与账号

### 2.1 默认访问地址

| 入口 | 默认地址 |
|---|---|
| 用户端 Web 首页 | `http://localhost:5173/` |
| 用户端帮助中心 | `http://localhost:5173/help` |
| 管理端登录 | `http://localhost:5173/login` |
| 管理端后台 | `http://localhost:5173/admin` |
| Java 后端 API | `http://localhost:8080/api` |
| Python AI 服务 | `http://localhost:8081` |

> 生产环境请将 `localhost:5173` 替换为实际部署域名。
> 小程序的后端地址在 `wechat-miniprogram/app.js` 的
> `globalData.apiBaseUrl` 中配置（默认 `http://127.0.0.1:8080/api`）。

### 2.2 账号体系

系统支持**四种进入方式**（登录页三个页签 + 游客入口）：

| 方式 | 入口 | 说明 |
|---|---|---|
| 用户名 + 密码 | 登录页「登录」页签 | 管理员与已注册用户 |
| 注册新账号 | 登录页「注册」页签 | 新用户自助注册 |
| 手机号 + 验证码 | 登录页「手机号登录」页签 | 首次使用该手机号会**自动注册** |
| 游客模式 | 登录页底部「游客模式进入」按钮 | 无需注册，一键生成临时身份 |

### 2.3 默认管理员账号

`schema.sql` 中的种子数据：

| 用户名 | 密码（文档声明） | 角色 |
|---|---|---|
| `admin` | `admin123` | `ADMIN` |

> **该账号已验证可正常登录**：种子哈希长度为 60（合法 BCrypt），
> 经与项目相同的 `BCryptPasswordEncoder` 实测可匹配 `admin123`。
>
> ⚠️ **生产环境请务必修改默认密码。**

### 2.4 账号与权限对照

| 角色 | 能做什么 |
|---|---|
| 游客 / `USER` | 浏览首页、帮助中心、文章、政策；在小程序中与智能体对话；政策问答（受配额限制） |
| `ADMIN` | 上述全部 **+** 文章管理、政策管理、配额管理、知识库上传与同步 |

> 管理端路由在前端有守卫（`/admin` 开头的路径检查本地 Token，无 Token 跳转登录页），
> 后端另有**双重校验**：URL 级 `/admin/**` 要求 `ADMIN` 角色，
> 方法级 `@PreAuthorize("hasRole('ADMIN')")` 再次校验。

> 需要**手动在地址栏输入** `http://localhost:5173/help/qa` 访问。

### 3.2 首页

**路径**：`/`（`Home.vue`）

**页面构成**

1. **顶部导航**：Logo「知伴AI」+「帮助中心」按钮 +「登录」按钮。
2. **Hero 区**：标题「知伴AI双端智能体平台」+ 副标题 +
   「进入帮助中心」按钮。
3. **三大方向卡片**（点击跳转到帮助中心对应 Tab）：
   - **政务服务** → 帮助中心「政务服务」Tab（`/help?tab=gov`）
   - **银发经济** → 帮助中心「银发经济」Tab（`/help?tab=silver`）
   - **文旅项目** → 帮助中心「文旅项目」Tab（`/help?tab=tourism`）
4. **精选文章**：自动加载最新 6 篇文章（`page=1, size=6`），
   点击标题进入文章详情；「查看全部」跳转 `/help/articles`。
5. **系统公告**：三条**静态**公告（当前未接入管理端）：
   - 【服务】银发康养智能体已上线，支持用药指导与康复计划
   - 【政策】政策问答支持来源追溯，回答均标注政策文件
   - 【提示】健康类建议仅供参考，请遵医嘱

**操作示例**

- 想快速看政策 → 点击「政务服务」卡片。
- 想浏览文章 → 直接点击「精选文章」中的标题。

### 3.3 登录 / 注册

**路径**：`/login`（`Login.vue`）

页面有三个页签 + 一个游客入口。

#### 3.3.1 用户名密码登录

1. 切到「登录」页签。
2. 输入用户名、密码。
3. 点击「登录」。

**成功后跳转**：`/admin/articles`（管理端文章管理）。

> ⚠️ 源码中登录成功后**固定跳转管理端** `/admin/articles`。
> 普通 `USER` 角色登录后会进入管理端页面，但接口会返回 403，
> 页面数据为空。普通用户建议改用**游客模式**（跳转 `/help`）。

#### 3.3.2 注册

1. 切到「注册」页签。
2. 填写用户名（≥3 字符）、密码（≥6 字符）、确认密码。
3. 点击「注册」。

**成功后**：提示「注册成功，请登录」，自动切回「登录」页签并回填用户名。

> 后端校验更严格：用户名只允许**字母、数字、下划线**（`^[a-zA-Z0-9_]+$`），
> 长度 3–64；密码 6–64 位。前端未校验字符集，若输入中文用户名，
> 提交时会收到「用户名只能包含字母、数字和下划线」。

#### 3.3.3 手机号登录

1. 切到「手机号登录」页签。
2. 输入 11 位手机号（`1[3-9]` 开头）。
3. 点击「获取验证码」。
4. 输入收到的 6 位验证码。
5. 点击「登录」。

**成功后跳转**：同用户名密码登录（`/admin/articles`）。

> ⚠️ **验证码如何获取**：当前短信通道**未接入**，
> 验证码只在**后端服务日志**中以 `log.info` 打印，手机号已脱敏。格式类似：
>
> ```
> 短信验证码已生成: phone=138****8000, code=483920
> ```
>
> 请到 Java 后端控制台查看。发送按钮有 **60 秒倒计时**，
> 短时间内重复请求会收到「验证码发送过于频繁」。

**首次使用某手机号**：会自动创建账号（用户名 `u` + 手机号）。

#### 3.3.4 游客模式

点击页面底部「**游客模式进入（无需注册）**」。

- 无需任何凭证，后端自动创建临时账号并返回 Token。
- **成功后跳转**：`/help`（帮助中心）。
- 每次点击都会创建一个**新的**游客账号。

> 游客账号用户名格式为 `guest_` + 16 位随机字符。

#### 3.3.5 返回首页

点击底部「返回首页」回到 `/`。

### 3.4 帮助中心

**路径**：`/help`（`HelpCenter.vue`）

三个 Tab，**首次切换时才加载数据**（懒加载，切换时显示骨架屏）。

#### 3.4.1 「政务服务」Tab

| 区块 | 内容 |
|---|---|
| 政策文件列表 | 政策标题 / 文号 / 发文机关 / 发布日期；「查看全部」跳 `/help/policies` |
| AI 政策问答 | 文本输入框 + 「提问」按钮，回答以蓝色提示框展示 |

**提问操作**

1. 在输入框填写问题，如「高龄补贴如何申请？」。
2. 点击「提问」。
3. 回答显示在下方提示框中。

> ⚠️ 此处的提问**需要登录**且**会消耗配额**（与 `/help/qa` 共用 `POLICY_QA` 配额）。
> 配额用尽会提示「您的政策问答配额已用完，请明日再来或联系管理员」。

#### 3.4.2 「银发经济」Tab

| 区块 | 内容 |
|---|---|
| 适老化政策与服务指南 | 政策表格 + 每行「详情」按钮（跳 `/help/policies?id=xx`） |
| 本月 AI 问答配额 | 配额进度条 |

> ⚠️ 该 Tab 请求时传的是 `category: '银发经济'`，
> 但后端政策接口的筛选参数是 **`policyType`**，`category` 会被忽略，
> 因此**筛选不生效**（实际返回全部政策）。

#### 3.4.3 「文旅项目」Tab

| 区块 | 内容 |
|---|---|
| 文旅资讯与帮助文章 | 文章表格 + 每行「阅读」按钮（跳 `/help/article/{id}`） |
| 常见问题 | FAQ 折叠面板 |

> ⚠️ FAQ 面板当前**无法正常显示问答内容**，见 [§8.5](#85-帮助中心常见问题面板为空)。

### 3.5 政策文件列表

**路径**：`/help/policies`（`PolicyList.vue`）

**页面构成**

- 顶部「返回帮助中心」。
- 筛选区：**分类下拉** + **关键词输入框** + 「搜索」按钮。
- 政策表格：政策标题 / 文号 / 发文机关 / 分类 / 发布日期 / 生效日期 + 「详情」按钮。
- 分页控件。

**操作**

1. 选择分类或输入关键词（支持回车触发搜索）。
2. 点击「搜索」。
3. 点击某行「详情」，弹出政策详情对话框。

**详情弹窗内容**：标题、文号、发文机关、分类、发布日期、生效日期、有效期至、正文。

> ⚠️ 该页存在多处字段名不匹配，实际表现：
> - 表格中「文号」「分类」列**显示为空**；
> - 详情弹窗中除标题外，**多数字段为空**；
> - 首页加载时因传 `page=0` 会触发「页码最小为1」错误提示。
>
> 详见 [§8.4](#84-前端字段名与后端不匹配) 与 [§8.6](#86-分页参数从-0-开始导致报错)。

### 3.6 AI 政策智能问答

**路径**：`/help/qa`（`PolicyQA.vue`）—— **需手动输入地址访问**

**页面构成**

- 对话区（用户气泡 + AI 气泡，「AI 正在思考...」加载态）。
- 输入区：多行文本框 + 「发送」按钮（支持 `Ctrl + Enter` 快捷发送）。
- 配额进度条。
- 快捷问题标签：「高龄补贴如何申请？」「老年人医保报销比例是多少？」
  「残疾人补贴政策有哪些？」「文旅消费券怎么领？」

**操作**

1. 输入问题（或点击快捷问题标签填入）。
2. 点击「发送」或按 `Ctrl + Enter`。
3. AI 回答以气泡形式追加到对话区。
4. 每次提问后**自动刷新配额**。

> ⚠️ 该接口**需要登录**。未登录会提示「未登录或登录已过期」。
> 配额类型为 `POLICY_QA`，新用户默认**总配额 100 次**，每次提问扣 1 次。
>
> ⚠️ 回答中**不会展示政策来源**。虽然后端 `PolicyAnswerVO` 返回了
> `sources` 数组（含政策标题、文号、发文机关、相似度），
> 但前端只取 `answer` 字段渲染。

### 3.7 帮助文章列表

**路径**：`/help/articles`（`ArticleList.vue`）

**操作**

1. 顶部「返回帮助中心」。
2. 右上角搜索框输入关键词，回车或点击搜索图标。
3. 点击文章条目进入详情。
4. 底部分页控件翻页。

> ⚠️ 列表项的摘要、分类标签、日期可能为空，且**首页会触发页码错误**，
> 详见 §8.4 与 §8.6。

### 3.8 文章详情

**路径**：`/help/article/:id`（`ArticleDetail.vue`）

**页面构成**：标题、分类标签、作者（默认「管理员」）、更新时间、正文（HTML 渲染）。

**操作**：点击左上角「返回列表」回到上一页。

> ⚠️ 后端 `HelpArticleVO` 没有 `author` 字段，作者恒显示为「管理员」；
> 更新时间字段名不匹配（前端读 `updatedAt`/`createdAt`，后端给 `createTime`/`updateTime`），
> 因此显示为空。

## 4. 管理端操作指南

> **前置条件：必须以 `ADMIN` 角色登录。**
>
> 所有管理端接口都有**双重权限校验**：
> 1. URL 级：`/api/admin/**` → `hasRole("ADMIN")`
> 2. 方法级：每个方法上的 `@PreAuthorize("hasRole('ADMIN')")`
>
> 非管理员访问会收到 **403 权限不足**。
>
> 默认管理员账号为 `admin` / `admin123`（已验证可登录），
> **生产环境请务必修改默认密码**。

### 4.1 进入管理端

**路径**：`/login` → 登录成功后自动跳转 `/admin/articles`

**管理端布局**（`AdminLayout.vue`）

| 区域 | 内容 |
|---|---|
| 左侧边栏 | Logo「知伴AI 管理后台」+ 三个菜单项 |
| 顶部栏 | 折叠按钮 +「前台首页」+「退出登录」 |
| 主内容区 | 路由视图 |

**菜单项**

| 菜单 | 路由 | 功能 |
|---|---|---|
| 文章管理 | `/admin/articles` | 帮助文章增删改查 |
| 政策管理 | `/admin/policies` | 政策增删改查 + 知识库上传与同步 |
| 配额管理 | `/admin/quota` | 用户配额查看与调整 |

**其他操作**

- 点击折叠图标（☰）收起/展开侧边栏。
- 点击「前台首页」跳转 `/`。
- 点击「退出登录」清除本地 Token 并跳转 `/login`。

> ⚠️ 前端路由守卫只检查**本地是否存在 Token**，不校验角色。
> 普通用户若有 Token 也能进入管理端页面，但接口会返回 403，页面无数据。

### 4.2 文章管理

**路径**：`/admin/articles`（`AdminArticle.vue`）

**列表字段**：ID / 标题 / 分类 / 作者 / 更新时间 / 操作

**新建文章**

1. 点击右上角「**新建文章**」。
2. 在弹窗中填写：
   - 标题（必填）
   - 分类（必填）
   - 作者（选填）
   - 内容（必填，支持 HTML）
3. 点击「确定」。

**编辑文章**

点击行内「编辑」，修改后点「确定」。

**删除文章**

点击行内「删除」，在确认框中确认。

> **删除是逻辑删除**（`deleted = 1`），数据仍保留在数据库中。

> ⚠️ **重要限制**：
> 1. 表单中的「**作者**」字段后端**不存在**，填写后会被丢弃。
> 2. 表单**没有「发布状态」开关**，而后端默认 `isPublished = 0`（未发布）。
>    因此**新建的文章不会出现在用户端列表**（用户端只显示已发布文章）。
> 3. 列表的「更新时间」列显示为空。
>
> 详见 [§8.4](#84-前端字段名与后端不匹配) 与 [§8.7](#87-新建文章不会出现在用户端)。

### 4.3 政策管理

**路径**：`/admin/policies`（`AdminPolicy.vue`）

该页面包含**两个卡片**：政策列表/编辑 + 知识库文档上传与同步。

#### 4.3.1 政策列表与编辑

**列表字段**：ID / 政策标题 / 文号 / 发文机关 / 分类 / 发布日期 / 操作

**新建政策**

1. 点击「**新建政策**」。
2. 填写弹窗表单：
   - 政策标题（必填）
   - 文号（必填），如 `国发〔2026〕1号`
   - 发文机关（必填）
   - 分类（必填，下拉选择：政务服务 / 银发经济 / 文旅项目）
   - 发布日期（日期选择）
   - 生效日期（日期选择）
   - 有效期至（日期选择，留空表示长期有效）
   - 政策内容（必填，多行文本）
3. 点击「确定」。

**编辑 / 删除**：同文章管理，删除为逻辑删除。

> ⚠️ **该表单与后端接口字段名严重不匹配，新建/编辑政策会失败或丢数据**：
>
> | 表单字段 | 后端要求 | 后果 |
> |---|---|---|
> | `documentNumber` | `docNumber` | 文号丢失 |
> | `category` | `policyType` | 政策类型丢失 |
> | `content` | `fullText` | 正文丢失 |
> | `expiryDate` | **不存在** | 被忽略 |
>
> 由于 `policyType` 是 `@NotBlank` 必填项，提交时会直接返回
> **400「政策类型不能为空」**，**新建政策当前无法成功**。
>
> 列表中的「文号」「分类」列也会显示为空。
> 详见 [§8.4](#84-前端字段名与后端不匹配)。

#### 4.3.2 知识库文档上传与同步

位于政策管理页下方的独立卡片。

**上传文档**

1. 选择目标集合（下拉）：
   - `govpolicy`（政务政策知识库）
   - `elderly`（银发康养知识库）
   - `tourism`（文旅导览知识库）
2. 通过「重建索引」开关设置上传后是否立即重建（默认开启）。
3. 点击上传区域选择文件。
4. 点击「**上传并同步**」。

**文件要求**

| 项 | 要求 |
|---|---|
| 扩展名 | `.txt` / `.md` / `.markdown` |
| 编码 | **UTF-8** |
| 大小 | ≤ **5MB** |
| 内容 | 必须有有效文本 |

**重建索引**

点击卡片右上角「**重建索引**」按钮，对当前所选集合执行全量重建。

**集合选择影响**

| 集合 | 影响的智能体 |
|---|---|
| `govpolicy` | 政务政策助手（政策问答） |
| `elderly` | 银发康养助手 |
| `tourism` | 文旅导览助手 |

> ⚠️ **大小限制的实际问题**：后端虽声明允许 5MB，
> 但 Spring 的 multipart 默认上限是 **1MB**，且未在配置中调大。
> 上传 1MB–5MB 的文件会得到 **500「系统内部错误」**，而非友好的 400 提示。
> 建议**单文件控制在 1MB 以内**。详见 [§8.3](#83-知识库上传大小限制冲突)。
>
> ⚠️ **上传不会写入政策数据库表**：文件会保存到知识库源目录并重建向量索引，
> 但**不会**在 `gov_policy_document` 表中创建记录。
> 因此「知识库有内容」与「政策列表有数据」是两件事，需要分别维护。

### 4.4 配额管理

**路径**：`/admin/quota`（`AdminQuota.vue`）

**列表字段**：用户ID / 配额类型 / 总配额 / 已使用 / 剩余 / 免费额度 / 使用率 / 操作

2. 选择「配额类型」：

   - `HELP_SEARCH`（帮助检索）

4. 点击右上角「刷新」重新加载。

**调整配额**

2. 在弹窗中修改（用户ID 与配额类型为只读）：

### 5.3 自动登录机制

小程序**启动时自动游客登录**（`app.js` → `onLaunch`）：

1. 从本地缓存读取 `token`。
2. 若无 Token，自动调用 `/api/auth/guest-login`。
3. 登录成功后缓存 Token，后续请求自动附加 `Authorization` 头。

**Token 失效处理**：收到 401 时自动清除 Token 并**重新游客登录**，
用户无需手动操作。

> 若游客登录失败（如后端未启动），小程序**仍可浏览公开内容**，静默降级。

1. 在底部输入框输入文字。
2. 点击发送（或键盘发送键）。
3. 用户消息立即上屏并**先写入本地缓存**。
4. 等待 AI 回复，期间显示加载态。
5. 回复以气泡形式追加。

**从其他页面带问题跳转**：支持 URL 参数 `q`，进入后**自动发送**。
例如从政策详情页点击「就本政策问 AI」。

1. 点击麦克风按钮**开始录音**（最长 60 秒）。
2. **再次点击停止录音**。
3. 录音文件自动上传识别。
4. 识别文本自动填入输入框并**自动发送**。

**录音参数**：16kHz 采样率、单声道、48kbps 码率、MP3 格式。

> ⚠️ **语音功能当前不可用**：语音引擎尚未接入
> （Python 侧 `VOICE_PROVIDER=none`），
> ASR 接口返回 **501 Not Implemented**，前端会提示「识别失败，请重试」或
> 「没有听清，请再说一次」。

#### 5.5.4 语音播报（TTS）

1. 点击「语音播报」开关开启。
2. 开启后，AI 每条回复会**自动朗读**。

> ⚠️ **语音播报当前不可用**：TTS 同样返回 **501**。
> 另外，播放音频的请求**未携带 Token**，即使引擎接入也会收到 401。
> 详见 [§8.2](#82-语音功能不可用)。

#### 5.5.5 对话缓存与离线

- 每个智能体的最近 **50 条**对话保存在**本地**（`wx.setStorageSync`）。
- 重新进入页面时优先展示本地缓存，**离线也能看到上次对话**。
- **离线时禁止发送**，并显示提示条「当前网络不可用，已显示本地缓存对话」。
- 网络恢复后自动隐藏提示条并提示「网络已恢复」。
- 点击提示条可**手动重试**。

#### 5.5.6 清空对话

点击清空按钮 → 确认框 → 清空当前智能体的本地缓存与消息列表，
重置为欢迎语。

> ⚠️ **清空只影响本地缓存**，服务端的会话与消息记录**不会被删除**。

## 7. 常见问题 FAQ

### 7.1 账号与登录

**Q1：忘记密码怎么办？**
A：系统当前**没有**找回密码功能。请联系管理员在数据库中重置，
或改用**手机号登录**（首次使用会自动注册新账号）。

**Q2：`admin` / `admin123` 登录失败？**
A：默认种子哈希已验证可匹配 `admin123`，因此若登录失败，通常是因为：
1. 数据库未执行过 `schema.sql` 的种子数据段，`admin` 用户不存在；
2. 密码曾被手工修改；
3. 请求的接口路径不是 `/api/auth/login`。

可用下面的 SQL 把密码重置为 `admin123`（哈希已实测有效）：

```sql
UPDATE `user`
SET `password` = '$2a$10$KqJA7uOT0CcRpebowhg45u/m3GQ3dqpf/HkTdgXzlF1Onsit34gAy'
WHERE `username` = 'admin';
```

> 生产环境请务必修改默认密码。

**Q3：手机号登录收不到验证码？**
A：短信通道未接入，验证码只打印在**后端服务日志**中。
请到 Java 后端控制台查找 `短信验证码已生成` 一行。

**Q4：游客模式能做什么？**
A：可以浏览帮助中心、文章、政策，以及在小程序中与智能体对话、做政策问答。
游客账号是临时的，每次进入都会新建。

**Q5：登录后为什么跳到了管理端？**
A：源码中登录成功后固定跳转 `/admin/articles`。
普通用户建议改用游客模式（跳转帮助中心）。

### 7.2 政策与文章

**Q6：为什么政策列表看不到文号/分类？**
A：前后端字段名不匹配（前端 `documentNumber`/`category`，
后端 `docNumber`/`policyType`）。详见 [§8.4](#84-前端字段名与后端不匹配)。

**Q7：为什么点开页面提示「页码最小为1」？**
A：部分页面把页码从 0 开始传，而后端要求 ≥1。
详见 [§8.6](#86-分页参数从-0-开始导致报错)。

**Q8：为什么帮助中心「常见问题」是空的？**
A：FAQ 数据结构不匹配。详见 [§8.5](#85-帮助中心常见问题面板为空)。

**Q9：政策问答有次数限制吗？**
A：有。配额类型 `POLICY_QA`，新用户默认**总配额 100 次**。
用尽后提示「您的政策问答配额已用完，请明日再来或联系管理员」。
管理员可在配额管理页调整。

### 7.3 智能体与对话

**Q10：Web 端能做智能体对话吗？**
A：不能。用户端 Web 只有政策问答（`/help/qa`）。
完整的三大智能体对话在**微信小程序**中。

**Q11：语音输入/播报没反应？**
A：语音引擎尚未接入，接口返回 501。
详见 [§8.2](#82-语音功能不可用)。

**Q12：切换智能体后对话记录会丢吗？**
A：不会。每个智能体的对话**独立缓存**（各最多 50 条），切换后各自恢复。

**Q13：清空对话后服务端还有记录吗？**
A：有。清空**只清除本地缓存**，服务端的会话与消息不会被删除。

**Q14：离线时能用吗？**
A：可以查看**本地缓存的最近对话**，但**不能发送**新消息。
网络恢复后会自动提示。

### 7.4 管理端

**Q15：管理端接口返回 403？**
A：当前登录账号不是 `ADMIN` 角色。
所有 `/api/admin/**` 接口都要求 ADMIN 权限。

**Q16：新建的文章为什么不显示在用户端？**
A：管理端表单没有「发布状态」开关，新建文章默认为**未发布**。
详见 [§8.7](#87-新建文章不会出现在用户端)。

**Q17：新建政策失败，提示「政策类型不能为空」？**
A：表单字段名与后端不匹配。详见 [§8.4](#84-前端字段名与后端不匹配)。

**Q18：上传知识库文档报 500？**
A：文件可能超过 Spring 默认的 1MB 上限。
详见 [§8.3](#83-知识库上传大小限制冲突)。

**Q19：上传文档后政策列表没有新增？**
A：上传只写入**向量知识库**，不会在 `gov_policy_document` 表创建记录。
两者需分别维护。

**Q20：配额管理里的 `HELP_SEARCH` 查不到数据？**
A：该配额类型当前没有业务逻辑使用，通常为空。

### 7.5 运维

**Q21：怎么确认 AI 服务是否正常？**
A：访问 `http://localhost:8081/api/v1/health`，
返回 `{"status":"ok",...}` 即正常。

**Q22：接口返回 429？**
A：两种可能：
1. **限流**：同一 IP + 方法每分钟超过 300 次请求
   （可通过 `RATE_LIMIT_MAX` 调整）。
2. **业务限流**：短信验证码发送过频，或政策问答配额用尽。

**Q23：怎么扩充知识库？**
A：两种方式：
1. 管理端「政策管理」页上传 `.txt` / `.md` 文件（推荐）。
2. 直接把文档放入 `python/knowledge_base/` 下对应子目录，
   然后调用 `POST /api/v1/build` 重建索引。

## 8. 已知问题与规避方法

以下问题均为**阅读源码时发现的实际缺陷**，会直接影响使用体验，如实记录并提供临时规避方法。

### 8.1 手机号加密与密钥配置（需运维关注）

**背景**：附件一 §8.1 要求敏感数据加密存储。当前 `user.phone` 已改为
**AES-256-GCM 密文**存储（格式 `enc1:base64(iv‖ct‖tag)`），
并新增 **HMAC-SHA256 盲索引** `phone_hash` 用于密文下的等值查询。
实现见 `com.zhiban.ai.security.PhoneCryptoService`。

**需要运维注意的三点**

1. **未配置密钥会退化为明文存储**：若未注入环境变量 `PHONE_ENC_KEY`，
   `PhoneCryptoService` 只打印 WARN 告警并继续以**明文**保存手机号。
   开发环境可用，但**生产环境必须注入**，否则不满足加密要求：

   ```bash
   PHONE_ENC_KEY=<32 字节 Base64 密钥>
   PHONE_INDEX_KEY=<HMAC 密钥，可选>
   ```

2. **存量明文数据需要回填**：迁移脚本
   `java-backend/src/main/resources/migration/V1_1__phone_encryption.sql`
   只做**结构迁移**（扩展 `phone` 列宽、新增 `phone_hash` 与唯一索引），
   不会在 SQL 层把已有明文加密。
   应用读取时对无 `enc1:` 前缀的值按明文处理，因此存量数据可继续使用。

3. **回填前的重复注册风险**：存量明文手机号在完成加密回填前
   `phone_hash` 为 `NULL`，此时**无法通过盲索引找到这些用户**。
   若老用户用手机号登录，会走「首次登录自动注册」分支，**可能创建重复账号**。
   建议尽快完成一次性加密回填。

**相关现象**

- 若日志出现「未配置 PHONE_ENC_KEY，手机号将以明文存储」，说明密钥缺失。
- 若出现同一手机号产生多个账号，通常是上述第 3 点导致。

### 8.2 语音功能不可用

**现象**：小程序语音输入提示「识别失败，请重试」；
语音播报无声音。

**原因**（两层）：

1. **引擎未接入**：Python 侧 `VOICE_PROVIDER` 默认为 `none`，
   `voice_service.py` 明确标注「接口契约已定义，具体实现待定」，
   TTS / ASR 均返回 **501 Not Implemented**。
2. **Token 未附加**（仅 TTS）：小程序 `speak()` 直接把 URL 赋给
   `audioCtx.src`，未带 `Authorization` 头，而 `/api/voice/tts` 需要登录。

**影响**：语音输入与语音播报功能**完全不可用**。

**规避方法**：暂时使用**文字输入**。
若需启用语音，需先决策语音方案（第三方云服务或自建部署），
再实现 `voice_service.py` 中的 `_synthesize_impl` / `_transcribe_impl`，
并修复 TTS 的 Token 传递。

### 8.3 知识库上传大小限制冲突

**现象**：上传 1MB–5MB 的文档，返回 **500「系统内部错误」**，
而不是友好的 400 提示。

**原因**：`AdminKnowledgeController` 声明允许 5MB，
但 `application.yml` **未配置** `spring.servlet.multipart.max-file-size`，
使用 Spring Boot 默认值 **1MB**。超限时抛
`MaxUploadSizeExceededException`，而 `GlobalExceptionHandler`
**没有单独处理该异常**，落到兜底 `Exception` 处理器 → 500。

**影响**：无法上传 1MB–5MB 的文档；错误信息不友好。

**规避方法**

- 把单个文档**拆分为 1MB 以内**的多个文件上传。
- 或在 `application.yml` 中增加配置后重启后端：

```yaml
spring:
  servlet:
    multipart:
      max-file-size: 5MB
      max-request-size: 10MB
```

### 8.4 前端字段名与后端不匹配

**现象**

| 页面 | 现象 |
|---|---|
| 政策列表 | 「文号」「分类」列为空 |
| 政策详情弹窗 | 除标题外多数字段为空 |
| 新建/编辑政策 | **失败**，提示「政策类型不能为空」 |
| 文章管理 | 「作者」字段无效，「更新时间」列为空 |
| 文章详情 | 作者恒为「管理员」，更新时间为空 |

**原因**：字段名对照

| 前端使用 | 后端实际字段 |
|---|---|
| `documentNumber` | `docNumber` |
| `category`（政策） | `policyType` |
| `content`（政策） | `fullText` |
| `expiryDate` | **不存在** |
| `author`（文章） | **不存在** |
| `updatedAt` / `createdAt` | `updateTime` / `createTime` |

**影响**：政策管理功能**实质不可用**（无法新建）；列表展示不完整。

**规避方法**

- 政策数据建议**直接通过 API 或数据库维护**，绕开管理端表单。
  可参考 `docs/API.md` §10.2 的正确请求体字段名。
- 列表字段缺失属于展示问题，不影响数据本身。

### 8.5 帮助中心「常见问题」面板为空

**现象**：帮助中心「文旅项目」Tab 的 FAQ 折叠面板**没有标题和内容**。

**原因**：前端把 `res.data` 当作 FAQ 条目数组，
直接读取 `item.question` / `item.answer`；
但后端 `/api/help/faq` 返回的是 **`List<GovPolicyVO>`**——
每个元素是一条**政策**，FAQ 数组嵌套在其 `faq` 字段中：

```json
[ { "id": 1, "title": "政策标题", "faq": [ { "question": "...", "answer": "..." } ] } ]
```

因此 `item.question` 恒为 `undefined`。

**影响**：FAQ 功能不可用。

**规避方法**：直接调用 `/api/help/faq` 查看原始数据；
或从政策详情中查看 `faq` 字段。

### 8.6 分页参数从 0 开始导致报错

**现象**：进入文章列表、政策列表、管理端文章/政策管理页时，
弹出错误提示「页码最小为1」，列表加载失败。

**原因**：这些页面传 `page: currentPage - 1`，首页时 `page = 0`；
而后端 `@Min(1)` 要求页码 ≥1，触发参数校验失败（HTTP 400）。

**受影响页面**：`ArticleList`、`AdminArticle`、`AdminPolicy`、
`HelpCenter`（三个 Tab 的加载方法）。

**不受影响**：`Home.vue`（传 `page: 1`）、`PolicyQA.vue`。

**规避方法**：暂无界面层规避手段，需修复前端传参。

### 8.7 新建文章不会出现在用户端

**现象**：管理端新建文章并保存成功，但用户端文章列表看不到。

**原因**：管理端表单**没有「发布状态」字段**，
提交的请求体不含 `isPublished`，后端 `HelpArticleRequest.isPublished`
默认值为 **`0`（未发布）**；
而用户端列表接口只返回 `is_published = 1` 的文章。

**影响**：所有通过管理端新建的文章都是草稿，用户端不可见。

**规避方法**：新建后直接在数据库中改为已发布：

```sql
UPDATE `help_content` SET `is_published` = 1 WHERE `id` = ?;
```

### 8.8 政策问答来源未展示

**现象**：小程序政策助手欢迎语称「回答会标注政策来源」，
但回复中看不到来源标注。

**原因**：

- 后端 `PolicyAnswerVO` **确实返回了** `sources` 数组
  （含政策标题、文号、发文机关、相似度分数）。
- 但前端（`PolicyQA.vue`、`HelpCenter.vue`）与小程序
  **只渲染 `answer` 字段**，忽略 `sources`。
- 同时 `chat_message.references` 列**未写入**，数据库也无追溯记录。

**影响**：政策回答的**可追溯性要求未在前端落地**。

**规避方法**：直接调用 `POST /api/policies/ask` 查看完整响应中的
`sources` 字段。

### 8.9 政策问答实质为关键词检索

**现象**：政策问答能返回结果，但召回质量依赖关键词命中。

**原因**：向量检索链路存在多处不匹配
（向量元数据无 `score` / `vector_id`，阈值 0.75 过滤掉全部 0 分结果，
`vector_id` 与文件名口径不一致），导致**几乎总是降级到关键词兜底检索**。

**影响**：问答效果**低于向量检索的设计预期**，
同义表达、口语化提问的召回率会偏低。

**规避方法**：提问时**尽量使用政策文件中的原词**
（如「高龄津贴」「长期护理保险」），提高关键词命中率。
详见 `docs/DATABASE.md` §9.3。

### 8.10 登录成功后固定跳转管理端

**现象**：普通用户用用户名/密码或手机号登录后，被带到 `/admin/articles`，
页面空白或报 403。

**原因**：`Login.vue` 的 `handleLogin` / `handlePhoneLogin`
中固定执行 `router.push('/admin/articles')`，未按 `role` 分流。

**影响**：普通用户体验不佳（但不影响游客模式）。

**规避方法**：普通用户请使用**游客模式**进入（跳转 `/help`）；
或登录后手动把地址改为 `/help`。
